# 第六章：Vue3 核心

## 6.1 Vue3 概述

Vue3 是 Vue.js 的最新主要版本，于 2020 年 9 月正式发布。相比 Vue2，Vue3 带来了以下关键改进：

- **Composition API**：更灵活的逻辑组织方式，解决大型组件代码复用困难的问题
- **更好的 TypeScript 支持**：底层完全用 TypeScript 重写
- **性能提升**：虚拟 DOM 重写，编译时优化，体积更小（Tree-shaking 友好）
- **Teleport、Suspense**：新增内置组件，处理特定场景
- **`<script setup>` 语法糖**：更简洁的组件编写方式

```bash
# 创建 Vue3 项目
npm create vue@latest my-app
cd my-app && npm install && npm run dev
```

## 6.2 Composition API

Composition API 是 Vue3 最重要的新特性，允许开发者按逻辑功能组织代码，而非按选项类型（data、methods、computed）分散。

### 6.2.1 setup 函数

`setup` 是 Composition API 的入口，在组件创建前执行。

```vue
<script>
import { ref } from 'vue'

export default {
  setup() {
    const count = ref(0)
    const increment = () => count.value++

    return { count, increment }
  }
}
</script>
```

### 6.2.2 `<script setup>`（推荐）

编译时语法糖，无需手动 return，更简洁。

```vue
<script setup>
import { ref, computed } from 'vue'

const count = ref(0)
const double = computed(() => count.value * 2)
const increment = () => count.value++
</script>

<template>
  <div>
    <p>{{ count }} x 2 = {{ double }}</p>
    <button @click="increment">+1</button>
  </div>
</template>
```

### 6.2.3 ref 与 reactive

**ref** — 用于基本类型的响应式包装：

```js
import { ref } from 'vue'

const name = ref('Vue')
const age = ref(25)

// JS 中通过 .value 访问
console.log(name.value) // 'Vue'
name.value = 'Vue 3'
```

**reactive** — 用于对象/数组的响应式代理：

```js
import { reactive } from 'vue'

const state = reactive({
  name: 'Vue',
  age: 25,
  items: [1, 2, 3]
})

// JS 中直接访问
console.log(state.name)
state.age = 26
state.items.push(4)
```

**使用原则：**

| 类型 | 推荐方式 |
|------|----------|
| 基本类型（string、number、boolean） | `ref` |
| 对象/数组 | `reactive` |
| 需要整体替换 | `ref`（重新赋值 .value） |
| 需要解构 | `toRefs` 配合 `reactive` |

### 6.2.4 computed

计算属性，具有缓存特性，依赖变化时自动更新：

```js
import { ref, computed } from 'vue'

const firstName = ref('张')
const lastName = ref('三')

// 只读
const fullName = computed(() => firstName.value + lastName.value)

// 可读可写
const fullNameRW = computed({
  get: () => firstName.value + lastName.value,
  set: (val) => {
    firstName.value = val[0]
    lastName.value = val.slice(1)
  }
})
```

### 6.2.5 watch 与 watchEffect

**watch** — 显式指定监听源：

```js
import { ref, watch } from 'vue'

const keyword = ref('')

// 监听单个 ref
watch(keyword, (newVal, oldVal) => {
  console.log(`搜索词: ${oldVal} → ${newVal}`)
})

// 监听多个源
const page = ref(1)
watch([keyword, page], ([newK, newP], [oldK, oldP]) => {
  console.log('关键词或页码变化')
})

// 深度监听对象
const user = ref({ name: 'Tom', age: 20 })
watch(user, (newVal) => {
  console.log('user 变化', newVal)
}, { deep: true, immediate: true })
```

**watchEffect** — 自动收集依赖，立即执行：

```js
import { ref, watchEffect } from 'vue'

const keyword = ref('')
const page = ref(1)

watchEffect(() => {
  // 自动追踪 keyword 和 page
  fetch(`/api/search?q=${keyword.value}&page=${page.value}`)
})
```

| 特性 | watch | watchEffect |
|------|-------|-------------|
| 指定监听源 | 是 | 否，自动收集 |
| 获取旧值 | 是 | 否 |
| 懒执行 | 是（默认） | 否，立即执行 |
| 适用场景 | 精确控制 | 副作用自动依赖追踪 |

## 6.3 组件系统

### 6.3.1 Props（父传子）

父组件向子组件传递数据：

```vue
<!-- 子组件 UserCard.vue -->
<script setup>
const props = defineProps({
  name: { type: String, required: true },
  age: { type: Number, default: 18 },
  avatar: String
})
</script>

<template>
  <div class="card">
    <img v-if="avatar" :src="avatar" />
    <h3>{{ name }}</h3>
    <p>年龄: {{ age }}</p>
  </div>
</template>
```

```vue
<!-- 父组件 -->
<template>
  <UserCard name="张三" :age="25" avatar="/avatar.jpg" />
</template>
```

### 6.3.2 Emits（子传父）

子组件通过事件向父组件发送消息：

```vue
<!-- 子组件 -->
<script setup>
const emit = defineEmits(['update', 'delete'])

const handleUpdate = () => {
  emit('update', { id: 1, name: '新名称' })
}

const handleDelete = () => {
  emit('delete', 1)
}
</script>

<template>
  <button @click="handleUpdate">更新</button>
  <button @click="handleDelete">删除</button>
</template>
```

```vue
<!-- 父组件 -->
<script setup>
import UserCard from './UserCard.vue'

const onUpdate = (data) => console.log('更新:', data)
const onDelete = (id) => console.log('删除:', id)
</script>

<template>
  <UserCard @update="onUpdate" @delete="onDelete" />
</template>
```

### 6.3.3 Slots（插槽）

```vue
<!-- 子组件 Card.vue -->
<template>
  <div class="card">
    <header>
      <slot name="header">默认头部</slot>
    </header>
    <main>
      <slot>默认内容</slot>
    </main>
    <footer>
      <slot name="footer"></slot>
    </footer>
  </div>
</template>
```

```vue
<!-- 父组件使用 -->
<template>
  <Card>
    <template #header>
      <h2>自定义标题</h2>
    </template>

    <p>卡片主体内容</p>

    <template #footer>
      <button>确定</button>
    </template>
  </Card>
</template>
```

作用域插槽（子传父数据到插槽）：

```vue
<!-- 子组件 -->
<script setup>
const items = ['Vue', 'React', 'Angular']
</script>

<template>
  <ul>
    <li v-for="item in items" :key="item">
      <slot :item="item">{{ item }}</slot>
    </li>
  </ul>
</template>
```

```vue
<!-- 父组件 -->
<template>
  <List>
    <template #default="{ item }">
      <span style="color: blue">{{ item }}</span>
    </template>
  </List>
</template>
```

## 6.4 生命周期钩子

Vue3 组合式 API 的生命周期钩子需要从 `vue` 导入：

```js
import {
  onBeforeMount,
  onMounted,
  onBeforeUpdate,
  onUpdated,
  onBeforeUnmount,
  onUnmounted
} from 'vue'

// setup 本身相当于 beforeCreate 和 created
console.log('组件初始化')

onBeforeMount(() => {
  console.log('挂载前')
})

onMounted(() => {
  console.log('已挂载，可访问 DOM')
})

onBeforeUpdate(() => {
  console.log('更新前')
})

onUpdated(() => {
  console.log('已更新')
})

onBeforeUnmount(() => {
  console.log('卸载前，清理副作用')
})

onUnmounted(() => {
  console.log('已卸载')
})
```

| 选项式 API | 组合式 API | 调用时机 |
|-----------|-----------|---------|
| `beforeCreate` | `setup()` | 实例初始化 |
| `created` | `setup()` | 实例创建完成 |
| `beforeMount` | `onBeforeMount` | DOM 挂载前 |
| `mounted` | `onMounted` | DOM 挂载完成 |
| `beforeUpdate` | `onBeforeUpdate` | 数据变化、DOM 更新前 |
| `updated` | `onUpdated` | DOM 更新完成 |
| `beforeUnmount` | `onBeforeUnmount` | 组件卸载前 |
| `unmounted` | `onUnmounted` | 组件卸载完成 |

## 6.5 模板语法

### 6.5.1 数据绑定

```vue
<template>
  <!-- 文本插值 -->
  <p>{{ message }}</p>

  <!-- 原始 HTML -->
  <p v-html="rawHtml"></p>

  <!-- 属性绑定 -->
  <img :src="imageUrl" :alt="imageAlt" />

  <!-- 动态属性名 -->
  <button :[event]="handler">点击</button>

  <!-- 布尔属性 -->
  <button :disabled="isDisabled">提交</button>
</template>
```

### 6.5.2 条件渲染

```vue
<template>
  <!-- v-if / v-else-if / v-else -->
  <div v-if="status === 'loading'">加载中...</div>
  <div v-else-if="status === 'error'">出错了</div>
  <div v-else>加载完成</div>

  <!-- v-show（CSS display 切换） -->
  <div v-show="isVisible">可见内容</div>
</template>
```

### 6.5.3 列表渲染

```vue
<template>
  <ul>
    <li v-for="(item, index) in list" :key="item.id">
      {{ index }}. {{ item.name }}
    </li>
  </ul>

  <!-- 对象遍历 -->
  <div v-for="(value, key) in obj" :key="key">
    {{ key }}: {{ value }}
  </div>
</template>
```

### 6.5.4 事件处理

```vue
<template>
  <!-- 内联处理 -->
  <button @click="count++">点击</button>

  <!-- 方法处理 -->
  <button @click="handleClick">点击</button>

  <!-- 传参 -->
  <button @click="handleClick($event, 'hello')">点击</button>

  <!-- 事件修饰符 -->
  <form @submit.prevent="onSubmit">
    <input @keyup.enter="onEnter" />
    <div @click.self="onDivClick">子元素不触发</div>
  </form>
</template>
```

## 6.6 状态管理：Pinia

Pinia 是 Vue3 官方推荐的状态管理库，是 Vuex 的继任者。

### 6.6.1 安装与配置

```bash
npm install pinia
```

```js
// main.js
import { createApp } from 'vue'
import { createPinia } from 'pinia'
import App from './App.vue'

const app = createApp(App)
app.use(createPinia())
app.mount('#app')
```

### 6.6.2 定义 Store

```js
// stores/counter.js
import { defineStore } from 'pinia'

export const useCounterStore = defineStore('counter', {
  // 状态
  state: () => ({
    count: 0,
    name: '计数器'
  }),

  // 计算属性
  getters: {
    doubleCount: (state) => state.count * 2
  },

  // 方法
  actions: {
    increment() {
      this.count++
    },
    async fetchData() {
      const res = await fetch('/api/count')
      this.count = await res.json()
    }
  }
})
```

### 6.6.3 使用 Store

```vue
<script setup>
import { useCounterStore } from '@/stores/counter'
import { storeToRefs } from 'pinia'

const store = useCounterStore()

// 使用 storeToRefs 保持响应性
const { count, doubleCount } = storeToRefs(store)
// 方法直接解构
const { increment } = store
</script>

<template>
  <p>计数: {{ count }}</p>
  <p>双倍: {{ doubleCount }}</p>
  <button @click="increment">+1</button>
</template>
```

## 6.7 Vue Router

Vue Router 是 Vue.js 的官方路由管理器。

### 6.7.1 基本配置

```bash
npm install vue-router
```

```js
// router/index.js
import { createRouter, createWebHistory } from 'vue-router'
import Home from '@/views/Home.vue'
import About from '@/views/About.vue'

const routes = [
  { path: '/', name: 'Home', component: Home },
  { path: '/about', name: 'About', component: About },
  {
    path: '/user/:id',
    name: 'User',
    component: () => import('@/views/User.vue'),  // 懒加载
    props: true  // 将路由参数作为 props 传递
  }
]

const router = createRouter({
  history: createWebHistory(),
  routes
})

export default router
```

### 6.7.2 注册与使用

```js
// main.js
import { createApp } from 'vue'
import App from './App.vue'
import router from './router'

createApp(App).use(router).mount('#app')
```

```vue
<!-- App.vue -->
<template>
  <nav>
    <router-link to="/">首页</router-link>
    <router-link to="/about">关于</router-link>
  </nav>
  <router-view />
</template>
```

### 6.7.3 路由守卫

```js
// 全局前置守卫
router.beforeEach((to, from) => {
  const isLoggedIn = localStorage.getItem('token')

  if (to.meta.requiresAuth && !isLoggedIn) {
    return { name: 'Login' }  // 重定向到登录页
  }
})

// 路由独享守卫
{
  path: '/admin',
  component: Admin,
  beforeEnter: (to, from) => {
    // 权限检查
  }
}
```

### 6.7.4 路由导航

```vue
<script setup>
import { useRouter, useRoute } from 'vue-router'

const router = useRouter()
const route = useRoute()

// 获取当前路由信息
console.log(route.params.id)
console.log(route.query.keyword)

// 编程式导航
router.push({ name: 'User', params: { id: 123 } })
router.replace({ path: '/login' })
router.go(-1)  // 后退一步
</script>
```

## 6.8 小结

- **Composition API** 按逻辑功能组织代码，解决大型组件代码复用问题
- **ref/reactive** 提供响应式数据，**computed** 提供缓存计算，**watch/watchEffect** 处理副作用
- **组件通信**：Props 传入，Emits 传出，Slots 处理内容分发
- **生命周期**：通过 `onMounted`、`onUnmounted` 等钩子管理组件生命周期
- **Pinia** 简洁高效，是 Vue3 状态管理的首选方案
- **Vue Router** 提供路由管理，支持懒加载和导航守卫
- 推荐使用 `<script setup>` 语法糖，代码更简洁
